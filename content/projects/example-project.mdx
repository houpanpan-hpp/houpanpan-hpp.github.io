## 它在解决什么

需要一个能长期写技术文章 + 项目展示 + 经验记录的地方。
Notion / 公众号 / 知乎都不够"自己"，所以自己搭。

## 设计要点

- **静态导出**：`next build` 直接产出 `out/`，扔到 GitHub Pages。
- **MDX**：文章里能嵌组件，比纯 Markdown 灵活。
- **Cmd+K 搜索**：构建期生成索引，客户端 Fuse.js 查询。
- **深色为主**：Cyberpunk 一点点，但不多。
